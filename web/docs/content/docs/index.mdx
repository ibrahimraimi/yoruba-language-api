title: Quick Start
description: Get Yoruba API up and running in minutes
---

The fastest way to get started is using the terminal:

```bash
git clone https://github.com/ibrahimraimi/yoruba-api.git
cd yoruba-api
make install
make db-init
make run
```

### Development Options

- `make install`: Install Python dependencies
- `make db-init`: Initialize the database with sample data
- `make run`: Run the API server locally with reload
- `make test`: Run integration and unit tests
